# Univia Tech · landing

Copia de prueba del sitio (artefactos de claude.ai), publicada en https://landing.univiatech.com (noindex).
Páginas (12): inicio (`/`), `plataforma/`, `planes/`, `politica-de-datos/`, `blog/` y 7 artículos en `blog/<artículo>/`.
Las rutas salen de `paginas_sitio.json`. `seguimiento.js` (del sitio original) se carga desde la raíz; aún no está en el repo.
Los leads van al CRM de QA (canal `landing-univia`).

No se edita a mano: la actualiza cada día `sincronizar_landing.py` (CENIT/MARCAS/univia_tech/material/sitio)
cuando cambia algún artefacto del sitio, después de publicarla en staging y QA. Se arma con `armar_landing_estatica.py`.
